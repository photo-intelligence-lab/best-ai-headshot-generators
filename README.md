## What the table doesn't show

- **Volume buys likeness.** Every tool produces some photos that don't look like you. More photos per dollar means more chances to find the five that do.
- **Range.** Headshot-only tools stop at office backdrops. Narkis uses the same personal model for LinkedIn, dating, travel and video.
- **Speed.** A Narkis model trains in a median 6.5 minutes; the others quote 15 minutes to 2 hours.
